# 📚 Course Enrollment Platform

![Platform Banner](https://media.giphy.com/media/xT9IgG50Fb7Mi0prBC/giphy.gif)

A modern **Course Enrollment Platform** built with **Spring Boot**, **React**, and **MySQL**.  
Enroll in courses, track stats, and manage courses seamlessly. Optimized for **dark & light themes**, with real-time statistics and beautiful animations.

---

## 🚀 Features

### 1️⃣ Explore & Enroll Easily
Browse a wide range of courses and enroll with a single click.  
![Enroll GIF](https://media.giphy.com/media/3oEjI6SIIHBdRxXI40/giphy.gif)

### 2️⃣ Learn Anytime, Anywhere
Access your course materials on-demand from any device.  
![Learn Anywhere GIF](https://media.giphy.com/media/l0HlOvJ7yaacpuSas/giphy.gif)

### 3️⃣ Expert Instructors
Learn from experienced instructors with real-world expertise.  
![Instructor GIF](https://media.giphy.com/media/3o7aCTPPm4OHfRLSH6/giphy.gif)

### 4️⃣ Real-Time Stats & Course Popularity
Track total courses, enrolled students, and course popularity dynamically.  
![Stats GIF](https://media.giphy.com/media/xT9KVH8I1e3fXGdZtG/giphy.gif)

### 5️⃣ Dark & Light Theme
Toggle between themes seamlessly, all components adapt automatically.  
![Dark Mode GIF](https://media.giphy.com/media/3o6Zt481isNVuQI1l6/giphy.gif)

### 6️⃣ Admin & User Roles
- Admins: manage students and courses  
- Users: enroll in courses, view profile

## 💻 Tech Stack

| Frontend | Backend | Database | Auth |
|----------|--------|---------|------|
| React.js | Spring Boot | MySQL | JWT |
| Tailwind CSS & Bootstrap | Spring Security | Hibernate/JPA | BCrypt Passwords |
| Axios | JdbcTemplate |  | Role-based Access Control |
